# Street Homes

A responsive front-end e-commerce demo built with HTML, CSS and vanilla JavaScript.

## Run it in VS Code
1. Extract `Street-Homes.zip`.
2. Open VS Code.
3. Choose **File → Open Folder** and select `Street-Homes`.
4. In Extensions, install **Live Server** by Ritwick Dey.
5. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server refreshes more conveniently while you edit.

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout, responsive design and visual styling
- `script.js` — product catalogue, search, category filters, sorting, wishlist, cart and checkout demo

## Features
- Responsive homepage and product catalogue
- Product search, category filtering and price sorting
- Wishlist saved in browser local storage
- Shopping bag with quantity controls and subtotal
- Checkout form demonstration (no real order or payment)
- Newsletter interaction demonstration

## Before presenting
- Replace sample products, prices and images with the company's approved catalogue.
- Check every image loads with an internet connection.
- This is a front-end demonstration only. It does not have a backend, real customer accounts, order management or payment processing.
